# 明朝卫所与海防鱼骨纪事表

> **在线预览**：<https://mllyx.github.io/ming-wei-suo-haifang/>
> **仓库地址**：<https://github.com/mllyX/ming-wei-suo-haifang>

以 SVG + HTML 实现的**可调节鱼骨纪事长卷**，记录明代卫所制度与海防体系的 44 件大事（1368—1644）。
版式算法取自博客园《利用 svg 结合 html 实现时间轴上下斜着展示子节点的鱼骨图》：
**固定骨刺倾角，按 `水平位移 = 离轴高度 ÷ tan(倾角)` 逐层算点连线**，再叠加一层"矩形避让"，
让时间相邻的骨刺自动推开，保证文字、骨线、图片永不相撞。

## 二、打开与查看

1. 双击 `index.html`。
2. 初始为 100% 缩放；`Ctrl + 滚轮` 缩放，按住空白处拖动平移。
3. 点「适应窗口」看全幅；点右上的「导出 SVG / 导出 PNG / 打印」出图。
4. **点画布上任意一条骨刺**：右侧抽屉会显示该事件的史料补充、出处，并可加图、改字。

## 四、加图片（保留的能力）

1. 点某条骨刺 → 右侧抽屉「配图」区 → **上传图片**（本地文件，自动压到 900px 内）或 **用网址**（粘贴 http(s)/data: 地址）。
2. 图片会嵌进该事件的骨刺末端，导出 SVG / PNG 时一并嵌入，文件自包含。
3. 想先看"图片位"排在哪：打开「图片占位框」，会出现虚线框 `＋ 图`。
4. 批量管理：面板底部「清除全部图片」。
5. 备份：面板「导出 JSON」可得 `{版式, 图片, 改过的文字}`，换机器后可复用。

> 用网址加的网络图片，导出 PNG 时可能被浏览器判为跨域而使画布污染；需要 PNG 时建议改为上传本地图。

## 五、重新生成与自检

需要 Node 18+（本机 v24 已装）：

```bash
cd 明卫所海防鱼骨图
node tools/build-svg.js     # 重新导出三份静态 SVG
node tools/build-md.js      # 由 data.js 重新生成《大事表》Markdown
node tools/check.js         # 纯几何自检：尺寸 / 重叠 / 越界（8 种参数组合）
node tools/verify.js segments=2   # 真实字体渲染自检（调用本机 Chrome 取 getBBox）
```

`verify.js` 的参数用 `key=value` 传递，例如 `node tools/verify.js segments=3 theme=moye angle=60`。

**本次验收结果**：8 种版式组合（长卷 / 双脊 / 三脊 / 60° / 86° / 三主题 / 加图位 / 隐藏要点 / 大字号）
在真实字体度量下 **文字互撞 0 处、出血越界 0 处、文字压线 0 处、标题截断 0 处**。

## 五点五、推送到 GitHub（本机网络受限时的做法）

本机到 `github.com:443` 的 git 传输会被重置（`Recv failure: Connection was reset`），
但 `api.github.com` 正常。因此推送有两条路：

```bash
# ① 网络正常时，常规方式
git push -u origin main

# ② 网络受限时，走 GitHub API 逐个上传对象（不经过 github.com 的 git 端口）
GITHUB_TOKEN=ghp_xxx node tools/push-api.js mllyX ming-wei-suo-haifang
```

`push-api.js` 会用 `git cat-file` 读取**精确的对象字节**，按同一 tree/author/message 重建提交，
因此远端提交 SHA 与本地完全一致，不会出现"内容相同但历史分叉"。
令牌只从环境变量读取，不写入任何文件。

## 六、版式原理

```
        纪年 · 标题 · 要点 · 图      ← 二级节点沿骨刺逐层外推
                    ╱
                  ╱   ← 一级骨刺：倾角 θ 固定
                ╱       水平位移 = 离轴高度 / tanθ   （θ=75° 时 ≈ 0.268 × 高）
   ────────────●──────────────────────────  时间脊（刻度 = 各事件锚点）
                ╲
                  ╲
                    ╲
```

1. 先在脊线上按年代定出每个事件的锚点（红点）；
2. 每条骨刺以固定倾角斜出，第 k 个节点的高度 h 已知，水平位移即 `h / tanθ`；
3. 节点处向文字列引一条短横线（骨刺→文字的"刺"），文字列左缘取骨刺最高点的位移量，因此整列不会压到斜线；
4. 时间相邻、空间相撞的骨刺，按"右侧事件只能右移"的规则逐条推开，直到盒子两两分离；
5. 因为要铺开标题 + 两条要点 + 图片，脊线刻度是**弹性**的：间距服务于阅读，标注的纪年为真实纪年，先后次序严格递增（图注已说明）。

## 七、史料与口径

- 44 条均标注出处，主要来自《明史》（兵志、食货志及相关列传）、《明太祖实录》《明太宗实录》、
  张燮《东西洋考》、江日昇《台湾外记》。
- 年号纪年用汉字（如"嘉靖卅二年"），公元纪年为事件发生的公历年。
- 卫所数字（如"内外卫三百二十九、守御千户所六十五""京籍三十八万、存者不及十四万"）依《明史·兵志》原文。
- 「宁波争贡」系年从《明史·食货志五》作嘉靖二年（1523）。
